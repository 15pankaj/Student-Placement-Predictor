#  Student Placement Prediction System

This is a simple **Django-based web application** that predicts whether a student is **Placed** or **Not Placed** based on academic and skill-related inputs.

The main goal of this project is to understand how **Machine Learning logic (NumPy & Pandas)** can be integrated with a **backend web framework (Django)**.

---

## Project Overview

In this project:
- The user enters student details like CGPA, no. of internships and no. of Projects.
- The backend processes this data using **NumPy and Pandas**.
- A simple machine learning–based logic predicts the placement result.
- The result is displayed on a web page.


##  Technologies Used

- **Python**
- **Django** (Backend)
- **NumPy** (Numerical computation)
- **Pandas** (Data handling)
- **HTML** (Frontend)
- **SQLite** (Default Django database, not used actively)
